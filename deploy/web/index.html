🔥 FLAME 30M · Rust

A 30-million-parameter language model trained from scratch on Rust code, Rust docs, English and compiler errors. It runs entirely in your browser: nothing you type leaves this page. It's a small base model: start some Rust and it continues it.

What is this?

    
FLAME is a small Rust framework (built on Candle)
      for training language models from scratch. This model: 8 Transformer layers, width 512,
      8k-token BPE vocabulary, 1024-token context, trained on 328M tokens. Validation loss 1.70
      overall, 0.97 on Rust code.

    
How does it run here?

    
The same Rust model code is compiled to WebAssembly. The page downloads the weights once
      (the browser keeps them for next time) and generates text on your CPU, one token at a time.
      Generation slows down as the text gets longer, because each new token re-reads the whole text so far.

    
Temperature 0 always picks the most likely token. The same prompt, settings and seed always give the same text.
